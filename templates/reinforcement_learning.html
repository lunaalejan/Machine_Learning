Reinforcement Learning

Reinforcement learning through an agent that learns to navigate through a GridWorld environment using rewards and Q-values.

What is Reinforcement Learning?

Reinforcement learning is a type of machine learning in which an agent interacts with an environment, performs actions, and receives rewards. The objective of the agent is to learn a strategy that allows it to obtain the highest possible accumulated reward.

Main Elements

Agent

An entity that makes decisions and learns through interaction with the environment.

Environment

GridWorld in which the agent must navigate until it reaches the target.

Actions

Up, down, left, and right.

Rewards

The agent receives rewards or penalties depending on its actions.
