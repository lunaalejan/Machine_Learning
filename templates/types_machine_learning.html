Machine Learning

Types of Machine Learning

Machine Learning can be divided into different types depending on how algorithms learn from data. The main types are Supervised Learning, Unsupervised Learning and Reinforcement Learning.

Supervised Learning

Supervised Learning uses labeled data. This means that the dataset contains input variables and a known output.

The model learns the relationship between the input data and the expected result so that it can make predictions with new observations.

Examples

Linear Regression, Logistic Regression and Naive Bayes.

Unsupervised Learning

Unsupervised Learning works with data that does not have predefined labels or expected results.

The algorithm analyzes the information and tries to discover patterns, structures or groups within the dataset.

Example

Customer segmentation using clustering.

Reinforcement Learning

Reinforcement Learning allows an agent to learn by interacting with an environment.

The agent receives rewards or penalties according to its actions and gradually learns which decisions produce better results.

Examples

Robotics, autonomous systems and game-playing artificial intelligence.
