Naive Bayes Evaluation Metrics

The evaluation metrics allow us to measure how well the Naive Bayes classification model performs when predicting whether a customer will make a purchase.

Model Performance

The following metrics are calculated using the test data, corresponding to 20% of the dataset.

Accuracy

{{ metrics.accuracy }}%

Measures the percentage of predictions that were correctly classified.

Precision

{{ metrics.precision }}%

Measures how many of the customers predicted as purchases were actually purchases.

Recall

{{ metrics.recall }}%

Measures how many actual purchases were correctly identified by the model.

F1-Score

{{ metrics.f1_score }}%

Combines Precision and Recall into a single performance measure.

Confusion Matrix

The confusion matrix shows the relationship between the actual classes and the predictions made by the Naive Bayes model.

Confusion Matrix Interpretation

Each value of the confusion matrix represents a different type of prediction made by the classification model.

TP

True Positive

The model correctly predicts that a customer belongs to class 1 (Purchase).

TN

True Negative

The model correctly predicts that a customer belongs to class 0 (No Purchase).

FP

False Positive

The model predicts Purchase, but the actual class is No Purchase.

FN

False Negative

The model predicts No Purchase, but the actual class is Purchase.

Model Evaluation Process

01. Dataset

The dataset contains information about customers and their purchasing behavior.

02. Train/Test Split

The data is divided into 80% for training and 20% for testing the model.

03. Naive Bayes

Gaussian Naive Bayes is trained using the selected independent variables.

04. Evaluation

The model is evaluated using Accuracy, Precision, Recall, F1-Score and the Confusion Matrix.

Variables Used

  • edad: Customer age.
  • visitas_web_mes: Number of website visits per month.
  • tiempo_sitio_min: Time spent on the website in minutes.
  • descuento_usado: Indicates whether the customer used a discount.
  • target: Purchase classification: 0 = No Purchase, 1 = Purchase.

The evaluation metrics provide an overview of the Naive Bayes model's ability to classify customers. Accuracy shows the general performance, while Precision and Recall provide more specific information about the positive class. The F1-Score combines both Precision and Recall to provide a balanced measure.
