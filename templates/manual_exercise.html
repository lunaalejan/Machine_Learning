Manual K-Means Simulation

This section presents a manual simulation of the K-Means clustering algorithm using 100 records and two numerical variables. Three iterations are performed to demonstrate the calculation of Euclidean distances, cluster assignments, centroid updates, within-cluster variation, and the evolution of the clusters.

1. Dataset Context

Customer Purchasing Behavior

The manual exercise uses a sample of 100 customer records obtained from the dataset selected for the customer segmentation project.

The purpose is to identify groups of customers with similar purchasing behavior using two numerical characteristics.

K-Means is appropriate for this exercise because the objective is to discover natural groups in unlabeled numerical data.

Exercise Configuration

  • Number of records: 100
  • Numerical variables: 2
  • Number of clusters: K = 3
  • Initial centroids: 3
  • Manual iterations: 3
  • Distance measure: Euclidean

2. Selected Numerical Variables

X — Total Quantity Purchased

This variable represents the total number of product units purchased by a customer during the period represented in the dataset.

Y — Total Spending

This variable represents the total monetary value of the customer's purchases during the analyzed period.

6. Distance Calculation

For every observation, the Euclidean distance to each centroid is calculated. The observation is assigned to the cluster associated with the smallest distance.

d = √[(x − xc)² + (y − yc)²]
