SUPERVISED LEARNING

Naive Bayes

Naive Bayes is a supervised machine learning algorithm based on Bayes' Theorem. It is mainly used for classification problems and predicts the probability that an observation belongs to a specific class.

What is Naive Bayes?

Naive Bayes is a supervised machine learning algorithm used for classification. It is based on Bayes' Theorem and calculates the probability that a data point belongs to a particular class. The algorithm is simple, fast, and especially useful when working with large datasets.

How does Naive Bayes work?

Naive Bayes analyzes the input features and calculates the probability of each possible class. It uses the available data to determine which class has the highest probability. The class with the highest probability becomes the final prediction.

Bayes' Theorem

Bayes' Theorem calculates the probability of an event based on previous knowledge and new evidence.

P(A|B) = P(B|A) × P(A) / P(B)

This equation allows the model to update the probability of a class when new information becomes available.

Why is it called "Naive"?

It is called "Naive" because the algorithm assumes that all input features are independent of each other. In real-world situations, this assumption is often not completely true, but the algorithm can still provide accurate and useful predictions.

Types of problems it can solve

Naive Bayes can solve different classification problems, such as:

  • Email spam detection
  • Sentiment analysis
  • Document classification
  • Medical diagnosis classification
  • News categorization

Main Characteristics

  • It is a supervised learning algorithm.
  • It is mainly used for classification.
  • It is based on Bayes' Theorem.
  • It assumes feature independence.
  • It is computationally efficient.
  • It works well with large datasets.

Advantages

  • Simple and easy to implement.
  • Fast training and prediction.
  • Requires relatively little training data.
  • Works well with high-dimensional datasets.
  • Useful for text classification.
  • Can handle multiple classes.

Limitations

  • The independence assumption may not be realistic.
  • Zero-frequency problems can occur.
  • It may perform poorly when features are highly correlated.
  • Probability estimates may not always be well calibrated.

Real-world Classification Example

A common example is email spam detection. The model can analyze words and characteristics found in an email and calculate the probability that the message is spam or not spam.

For example, if an email contains words frequently associated with spam, Naive Bayes can assign a high probability to the "Spam" class.

Gaussian Naive Bayes

Gaussian Naive Bayes is a variant of the Naive Bayes algorithm designed for continuous numerical data. It assumes that the values of each feature follow a Gaussian, or normal, distribution within each class.

It is useful when the input variables are numerical, such as age, temperature, height, weight, income, or other continuous measurements. Gaussian Naive Bayes is commonly implemented using GaussianNB from Scikit-learn.
