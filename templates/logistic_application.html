Supervised Learning

Logistic Regression Application

This application implements a Binary Logistic Regression model to classify customer purchase behavior using the number of monthly visits to a website.

Problem Context

Problem

The model analyzes customer website activity to determine whether a customer is likely to belong to the Purchase or No Purchase class.

Data

The dataset contains information about customers, including age, income, website activity, previous purchases, discounts and a binary target variable.

Independent Variable

visitas_web_mes
Represents the number of visits made by a customer to the website during one month.

Target Variable

target
The binary variable that contains the class that the model attempts to predict.
