Naive Bayes Classification

A Machine Learning model used to classify customers and predict their behavior based on different characteristics.

1. Problem Context

Customer Behavior Prediction

The company wants to predict customer behavior using information related to their characteristics and activity on the website.

For this purpose, a Gaussian Naive Bayes classification model is used to analyze different variables and determine the class of a new customer.

2. Dataset Information

Customer Dataset

The dataset contains information about customers and their interactions with a website.

  • edad: Customer's age.
  • visitas_web_mes: Number of website visits per month.
  • tiempo_sitio_min: Time spent by the customer on the website.
  • descuento_usado: Indicates whether the customer used a discount.
  • target: Variable representing the class to predict.

Independent Variables

The variables used by the model to perform the classification are:

edad visitas_web_mes tiempo_sitio_min descuento_usado

3. Target Variable

Target

The target variable represents the result that the model must predict for each customer.

4. Classes

0

No Purchase

The customer does not make a purchase.

1

Purchase

The customer makes a purchase.
