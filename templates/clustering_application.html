K-Means Clustering Application

This section presents the implementation of K-Means clustering using the Online Retail dataset. The objective is to identify groups of customers with similar purchasing behavior using machine learning techniques.

Dataset Context

The dataset used in this application is the Online Retail dataset, which contains transactional information from a UK-based online retailer.

Each transaction includes product information, quantity, price, customer identification and purchase date.

For clustering purposes, transactions were transformed into customer-level information.

Selected Variables

  • TotalQuantity: Total number of products purchased by each customer.
  • TotalSpending: Total monetary value spent by each customer.

Data Preprocessing

  1. Removed records without CustomerID.
  2. Removed duplicated transactions.
  3. Removed invalid purchases with Quantity or UnitPrice values less than or equal to zero.
  4. Calculated TotalSpending: Quantity × UnitPrice.
  5. Grouped transactions by customer.
  6. Applied StandardScaler before K-Means.

K-Means Configuration

The clustering model was implemented using Scikit-learn.

  • Algorithm: K-Means
  • Number of clusters: 3
  • Initialization: n_init = 10
  • Random state: 42
  • Scaling method: StandardScaler

Cluster Interpretation

Cluster 1: Represents the majority of customers with lower purchasing quantity and spending levels compared with the other groups.

Cluster 2: Represents a small group of customers with extremely high purchase quantities and spending values.

Cluster 3: Represents high-value customers with important purchasing activity, but below the values observed in Cluster 2.
