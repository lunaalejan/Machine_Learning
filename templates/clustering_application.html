Machine Learning Module

K-Means Clustering Application

This section presents the implementation of K-Means clustering using the Online Retail dataset. The objective is to identify groups of customers with similar purchasing behavior using unsupervised machine learning techniques.

Dataset Context

Online Retail Dataset

The dataset used in this application is the Online Retail dataset, which contains transactional information from a UK-based online retailer.

Each transaction contains information about products, quantities, prices, customers, and purchase information.

For clustering purposes, transactional data was transformed into customer-level information to analyze purchasing behavior and discover natural customer groups.

Selected Variables

TotalQuantity

Represents the total number of products purchased by each customer.

TotalSpending

Represents the total monetary value spent by each customer. This variable was calculated using Quantity × UnitPrice.

Data Preprocessing

1. Data Cleaning

Records without CustomerID were removed and duplicated transactions were eliminated.

2. Data Filtering

Transactions with invalid Quantity or UnitPrice values were removed.

3. Feature Engineering

A new variable called TotalSpending was created by multiplying Quantity by UnitPrice.

4. Customer Aggregation

Transactions were grouped by CustomerID to obtain customer-level purchasing information.

5. Feature Scaling

StandardScaler was applied because the numerical variables have different scales.

6. Final Dataset

After preprocessing, 4,338 customer records were used for the K-Means clustering model.

K-Means Configuration

Scikit-learn Implementation

The clustering model was implemented using the Scikit-learn library. K-Means was selected because it is an unsupervised learning algorithm capable of grouping observations according to their similarity.

  • Algorithm: K-Means
  • Number of clusters (K): 3
  • Initialization method: n_init = 10
  • Random state: 42
  • Feature scaling: StandardScaler

The algorithm assigns each customer to the closest centroid according to distance calculations and updates centroid positions until the clustering process converges.

Model Evaluation

Silhouette Score: {{ silhouette_score }}

The silhouette score evaluates how well separated the generated clusters are. A higher value indicates that observations are generally closer to their assigned cluster than to neighboring clusters.

The obtained score of 0.9574 indicates strong separation between the identified customer groups in this dataset.

Final Interpretation

Customer Segmentation Results

The K-Means algorithm successfully identified three different customer groups based on purchasing behavior. The clusters were created according to similarities in total purchased quantity and total spending.

The largest cluster represents regular customers with lower purchasing values. These customers form the majority of the dataset.

The second cluster represents a small group of customers with extremely high purchasing activity. These customers show significantly different behavior compared with the rest of the dataset.

The third cluster represents high-value customers with important purchasing activity. Their behavior is between regular customers and the highest-value group.

Importance of the Results

Customer segmentation using K-Means allows organizations to discover hidden patterns inside large datasets. These groups can support business analysis, customer relationship strategies, and data-driven decision-making.

Key Idea

This clustering application demonstrates how unsupervised learning can transform transactional data into meaningful customer groups. By applying preprocessing techniques, feature scaling, and K-Means clustering, the model was able to identify patterns and visualize customer behavior without predefined labels.
