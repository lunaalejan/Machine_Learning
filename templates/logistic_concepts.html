Supervised Learning

Logistic Regression

Logistic Regression is a supervised machine learning algorithm used to solve classification problems. It estimates the probability that an observation belongs to one of two possible classes.

What is Logistic Regression?

Logistic Regression is a statistical and machine learning method used mainly for classification. Instead of predicting a continuous numerical value, the model calculates the probability that an observation belongs to a specific class. The predicted probability is converted into a classification using a decision threshold.

Why is it a Classification Algorithm?

Although its name includes the word "regression", Logistic Regression is considered a classification algorithm because its final result is a class or label. The model first estimates a probability between 0 and 1 and then assigns the observation to one of the available classes.

Binary Classification

Binary classification is a problem in which the target variable contains only two possible classes. Examples include yes or no, approved or rejected, low risk or high risk, and purchase or no purchase.

Independent Variable

The independent variable is the input used by the model to make a classification. In this project, the Logistic Regression model uses monthly web visits as the independent variable.

Target Variable

The target variable is the value that the model attempts to predict. In this implementation, the target variable is target, which represents the customer's purchase classification.

Classes or Labels

Classes are the possible categories that can be predicted by the classification model. This project works with two classes: Class 0 and Class 1.

Probability

Logistic Regression calculates the probability that an observation belongs to a particular class. The probability ranges from 0 to 1. A value closer to 1 indicates a greater probability of belonging to the positive class.

Binary Classes Used in the Project

0
No Purchase

The customer is classified as not making a purchase.

1
Purchase

The customer is classified as making a purchase.

Classification Threshold

A classification threshold determines how the probability generated by the model is converted into a class. A common threshold is 0.50.

Probability below 0.50 → Class 0
Probability equal to or greater than 0.50 → Class 1

Linear Regression vs Logistic Regression

Characteristic Linear Regression Logistic Regression
Main purpose Predict numerical values Predict categories or classes
Output Continuous value Probability and class
Example Predict a product price Predict purchase or no purchase
Type of problem Regression Classification

Logistic Regression in This Project

The model will analyze the number of monthly visits made by a customer to a website and use that information to classify the customer into one of two possible categories: No Purchase or Purchase. This implementation will use a dataset loaded from a CSV file with Pandas and a Logistic Regression model implemented with scikit-learn.
