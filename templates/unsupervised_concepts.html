Unsupervised Machine Learning

Unsupervised machine learning is a type of machine learning in which algorithms analyze data without predefined labels or target values. Its purpose is to discover hidden patterns, structures, relationships, or groups that naturally exist within a dataset.

What is Unsupervised Learning?

Unlabeled Data

Unlike supervised learning, unsupervised learning works with data that does not contain a known target or predefined class. The algorithm explores the available variables and attempts to identify meaningful structures by itself.

Pattern Discovery

The main objective is to discover similarities, differences, associations, and patterns among observations. These patterns can help understand complex datasets and support decision-making.

What is Clustering?

Clustering is an unsupervised learning technique used to divide observations into groups called clusters. Records within the same cluster should be more similar to each other than to records belonging to other clusters.

Clustering is commonly used in customer segmentation, behavioral analysis, pattern recognition, image analysis, market research, anomaly exploration, and many other applications where natural groups need to be identified without predefined labels.

What is K-Means?

K-Means Clustering

K-Means is a clustering algorithm that divides a dataset into a predefined number of groups, represented by the value K.

The algorithm assigns each observation to the nearest cluster center and repeatedly recalculates those centers until the cluster assignments or centroid positions stabilize.

For this project, the value of K is set to 3, meaning that the observations will be organized into three clusters.

What is a Centroid?

Cluster Center

A centroid represents the center of a cluster. In K-Means, each cluster has one centroid whose coordinates are calculated using the mean values of all observations assigned to that cluster.

For a dataset containing two numerical variables, the centroid can be represented as:

C = (x̄, ȳ)

where x̄ is the mean of the first variable and ȳ is the mean of the second variable.

After each iteration, the centroid changes according to the observations currently assigned to its cluster.

Euclidean Distance

K-Means needs a method for determining which centroid is closest to each observation. One of the most common measures used for numerical data is Euclidean distance.

d = √[(x − xc)² + (y − yc)²]

The observation is assigned to the cluster whose centroid produces the smallest distance.

Distance Example

Suppose a record has the coordinates (30, 40) and one centroid is located at (25, 25).

d = √[(30 − 25)² + (40 − 25)²]
d = √(25 + 225)
d = √250 ≈ 15.81

This calculation is repeated for all centroids. The record is then assigned to the cluster associated with the shortest distance.

How Does K-Means Work?

1

Select K

Define the number of clusters that the algorithm will create.

2

Initialize Centroids

Select or generate an initial center for each cluster.

3

Calculate Distances

Calculate the distance between every observation and every centroid.

4

Assign Clusters

Assign each observation to the cluster with the nearest centroid.

5

Update Centroids

Calculate the mean coordinates of the observations belonging to each cluster.

6

Repeat

Repeat the assignment and centroid update process until convergence or a stopping condition is reached.

What is an Iteration?

Repeating the K-Means Process

An iteration is one complete cycle in which observations are assigned to their nearest centroid and new centroid coordinates are calculated.

During the first iteration, assignments are based on the initial centroids. The updated centroids are then used in the second iteration. This process continues until the stopping condition is reached.

In the manual exercise developed for this project, three iterations are performed to demonstrate how cluster assignments and centroid positions evolve.

Convergence

K-Means is considered to have converged when the cluster assignments or centroid positions no longer change significantly between iterations, or when another predefined stopping criterion is reached.

Within-Cluster Variation

Measuring Cluster Compactness

One objective of K-Means is to create compact clusters. This means that observations belonging to the same cluster should remain relatively close to their centroid.

A common K-Means objective is to minimize the sum of squared distances between observations and their assigned centroids. Lower within-cluster dispersion generally indicates more compact groups for the selected value of K.

In the manual exercise, the within-cluster variation is compared across the three iterations to observe how the cluster configuration changes.

Advantages and Limitations

Advantages

  • Simple to understand and implement.
  • Efficient for many numerical datasets.
  • Produces clearly defined cluster assignments.
  • Centroids provide useful summaries of groups.
  • Useful for exploratory data analysis and segmentation.

Limitations

  • The value of K must be selected.
  • Results can depend on centroid initialization.
  • It can be sensitive to outliers.
  • Variables with different scales may influence distance calculations.
  • It may perform poorly when clusters have complex shapes, very different densities, or substantially different sizes.

Why is Feature Scaling Important?

Because K-Means relies on distances, numerical variables with much larger scales can have a stronger influence on the clustering process. Standardization or another appropriate scaling method can therefore be important when variables use different units or ranges.

K-Means in This Project

Customer Segmentation

In this project, K-Means is used to explore groups of customers with similar purchasing behavior.

Numerical purchasing variables can be used to represent customer behavior. K-Means analyzes similarities among these observations and assigns customers to clusters according to their proximity to the corresponding centroids.

The next section presents a manual simulation using 100 records and three iterations. The clustering application then implements K-Means with Scikit-learn using a larger dataset.

Key Idea

K-Means transforms a collection of unlabeled numerical observations into groups based on similarity. It begins with K centroids, assigns observations according to distance, recalculates the cluster centers, and repeats the process. Understanding these steps is essential for interpreting the manual simulation and the automated clustering application developed in this project.
