Application

Estimating Computer Prices Based on Storage Capacity

1. Problem context

A computer retailer wants to understand how much a computer's storage capacity influences its selling price, so the pricing team can estimate a fair market value for new listings based on their hardware specifications. Right now, prices are set somewhat informally, which leads to inconsistent pricing across similar machines and makes it harder to justify prices to customers or spot listings that are priced too high or too low.

  • What is the problem? There is no consistent, data-driven way to price a computer based on its storage capacity, which leads to prices that vary more than the hardware itself would justify.
  • What phenomenon is being analyzed? The relationship between a computer's storage capacity (measured in GB or TB) and its market price, under the assumption that price tends to increase as storage capacity increases.
  • What do the data represent? Historical records of computers that have already been sold or listed, where each record pairs a unit's storage capacity with its actual selling price.
  • What is the purpose of applying Linear Regression? Linear Regression allows the price to be modeled as a continuous numeric value that changes proportionally with storage capacity, capturing the overall trend from historical data so it can be used to estimate prices for new, unseen computers.
  • What value does the model try to predict? The estimated selling price of a computer, given its storage capacity.

2. Variables

Independent variable (X)

Storage capacity (GB)

The input variable used to make the prediction. It is quantitative (measured in gigabytes) and is expected to have a proportional relationship with the price, which makes it appropriate for a Simple Linear Regression model.

Dependent variable (Y)

Price

The variable the model tries to predict. It is quantitative (a continuous numeric value expressed in currency).

Both variables are quantitative and numeric, and the relationship between them can be reasonably approximated with a straight line, which satisfies the requirements for implementing a Simple Linear Regression.

3. Dataset

Number of records

1,303 records

Independent variable

Storage capacity
Unit: GB

Dependent variable

Price
