Linear Regression — Concepts

Before jumping into the practical implementation, let's walk through the core ideas that explain how Linear Regression actually works.

What is Linear Regression?

Linear Regression is a supervised learning algorithm used to model the relationship between two variables by fitting a straight line to a set of observed data points.

Once that line is fitted, it can be used to estimate the value of one variable based on the value of the other — even for cases the model has never seen before.

What types of problems can be solved using Linear Regression?

Estimating numeric values

Predicting a price, a score, a temperature, or any other quantity that changes continuously.

Studying trends

Understanding whether one variable tends to increase or decrease as another one changes.

Forecasting outcomes

Estimating a future or unknown result from a single known input value.

Independent and dependent variable

Input

Independent variable (X)

The variable used as the known input to make a prediction. It's the value you already have and feed into the model.

Output

Dependent variable (Y)

The variable the model tries to predict. Its value is assumed to depend, at least partly, on the independent variable.

Relationship between variables

Linear Regression assumes there is a linear relationship between X and Y — meaning that, on average, Y changes at a fairly constant rate as X changes. This relationship can be positive (Y increases as X increases) or negative (Y decreases as X increases).

Positive relationship

As X increases, Y also tends to increase. Example: more hours studied, higher exam scores.

Negative relationship

As X increases, Y tends to decrease. Example: more years of use, lower resale value.

The regression line

The regression line is the straight line that best summarizes the relationship between X and Y. It is chosen so that the overall distance between the line and all the observed data points is as small as possible.

This line is described by a simple mathematical equation, where the slope tells you how much Y changes for each unit increase in X.

Y = mX + b m = slope · b = intercept

Prediction

Once the regression line has been fitted using existing data, it can be used to predict the value of Y for any new value of X — even one that wasn't part of the original dataset. The model simply plugs the new X value into the line's equation to produce the estimated Y.

A simple example

Imagine you want to predict a student's exam score based on how many hours they studied.

  • Independent variable (X): hours studied
  • Dependent variable (Y): exam score

After training on data from previous students, the model finds a line showing that, on average, each extra hour of study is associated with a certain increase in score. If a new student studies for 5 hours, the model uses that line to estimate what their exam score is likely to be.
