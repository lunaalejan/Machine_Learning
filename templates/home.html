Machine Learning

What is Machine Learning?

Machine Learning is a branch of artificial intelligence that allows a system to improve its performance on a task through experience, instead of following rules written manually by a person.

Rather than programming fixed instructions for every situation, the system is shown example data , and it adjusts its internal parameters until it recognizes patterns that let it predict or decide on new data it has never seen before.

What is the main purpose of Machine Learning?

Automating decisions

Solving repetitive or complex tasks without needing to manually program every rule.

Finding patterns

Discovering relationships and trends in data that are not always obvious at first glance.

Predicting the future

Estimating future values or behaviors based on what has been observed in the past.

Data feeds the training process; during training, the algorithm adjusts its parameters until it becomes a model ; and that trained model is what generates predictions when it receives new information it has not seen before.

The importance of data

Without data there is no learning. A Machine Learning model does not know anything on its own; everything it learns comes from the examples it was trained on.

Incomplete, mislabeled, or unrepresentative data can make the model learn the wrong patterns, no matter how many records are used.

In general, the more varied examples a model sees during training, the better it generalizes its behavior to new cases.

If historical data contains biases, the model can learn and reproduce them in its predictions, which is why reviewing the source and quality of the data is essential.
Classification

Main Types of Machine Learning

Supervised Learning

Supervised Learning

Definition

The model learns from a dataset in which every example already includes the correct answer, known as a label. It adjusts its parameters by comparing its predictions against those known answers.

Key characteristics
  • Requires labeled data
  • Learning is guided by a known correct output
  • Performance can be measured against real answers
  • Usually requires more effort to prepare the data
Problems it can solve
  • Classification, such as spam detection
  • Regression, such as price prediction
  • Risk or fraud scoring
Unsupervised Learning

Unsupervised Learning

Definition

The model works with data that has no labels or known answers. Instead of predicting a specific output, it explores the data to find structures, groups, or relationships.

Key characteristics
  • Works with unlabeled data
  • There is no known correct answer
  • Focuses on discovering hidden structure
  • Results often require human interpretation
Problems it can solve
  • Clustering, such as customer segmentation
  • Anomaly detection
  • Pattern discovery and dimensionality reduction
Reinforcement Learning

Reinforcement Learning

Definition

An agent interacts with an environment, taking actions and receiving rewards or penalties as feedback. Over time, it adjusts its strategy to maximize the total reward.

Key characteristics
  • Learns through trial and error
  • Feedback comes as rewards or penalties
  • Actions can affect future states
  • Balances exploration and known actions
Problems it can solve
  • Game-playing agents
  • Robotics and autonomous navigation
  • Route and resource optimization

Recommendations

Voice assistants

Recognize speech and answer questions or execute commands.
